# 后台进程整理器 · V0.1

一个 Windows 本地小工具，用于扫描当前运行进程，并由用户手动勾选后强制结束。

## 功能

- 扫描全部可见进程
- 显示进程名、PID、工作集内存、可执行文件路径
- 按内存占用从高到低排列
- 搜索进程
- 手动勾选后强制结束整个进程树
- 二次确认，避免误杀
- 显示当前物理内存占用
- 系统关键进程永久保护
- 本程序自身永久保护
- ChatGPT/OpenAI 进程永久保护
- 常见浏览器默认保护，避免把当前 ChatGPT 会话一起关闭
- 可隐藏受保护进程

## 注意

强制结束任何普通应用仍可能造成未保存数据丢失。浏览器保护可以手动关闭，但这样可能会关闭当前网页和聊天。

程序通过管理员权限启动，以便结束普通权限下无法结束的用户进程；受保护名单中的系统关键进程仍然不可选。
